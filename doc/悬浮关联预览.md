# 局部图谱分支与悬浮关联预览

## 已确认范围

1. 手动展开、收起和保留一层真实关联；收起不删除原有或其他分支共用的节点。
2. 悬浮非中心文件节点时，主图临时层与旁边关系小图同时淡入一层关联；离开整个预览区域后淡出。
3. 两处预览均能继续悬浮逐层探索，单一小图与路径栏返回祖先，避免无限叠窗或自动递归。
4. 图谱右侧工具栏提供当前视图独立的“悬浮关联”开关，默认关闭；关闭恢复普通节点预览。
5. 开启时普通悬浮显示关系，按住 Ctrl 使用原有笔记预览；现有关联面板的精确段落预览保持可用，Hover Editor 不修改。
6. 来源关系默认不扩散，遵循当前入链、出链和筛选；高连接节点分批展示并提示总数。
7. 临时预览不加入核心图数据、不改变原图力学、深度或正式统计。手动分支经过正式图谱数据管线。
8. 任意预览边可按真实两端查看引用原文；中心固定由当前图谱统一管理，最后一个使用方释放后恢复原状态。

## 实现前验收标准

- 数据：真实一跳、方向、来源过滤、稳定分页、索引更新、共享节点与边去重。
- 悬浮：停留触发、双处同步、离开宽限、连续探索、循环返回、取消过期请求、减少动画。
- 接线：常驻开关、普通及圆形菜单、手动保留、Ctrl 预览分流、实际文件对的引用详情。
- 宿主：先在独立库验证单实例悬浮接入与临时绘制；主图位置、焦点、原有段落预览及其他图谱实例不受误改。
- 心衰：使用真实笔记副本验证两处同一邻居集合、至少两层探索；第一功能的 21 个位置、34 处引用及标题／块定位继续通过。
- 交付：正式构建、针对性和完整回归、界面截图验收后部署 CMBK，保留配置、笔记及 Hover Editor。

## 使用方式

CMBK 隐藏了视图标题栏，最终将开关放在图谱内右侧工具区，设置折叠后仍保留可见。

1. 打开局部关系图，启用 Extended Graph，再点击右侧工具栏的“悬浮关联”。紫色表示开启，开关只影响当前视图。
2. 在附属文件节点停留约 300 毫秒，同时显示主图紫色临时节点及旁边的小图；可移入任一预览继续悬浮探索。离开整个区域后，先留 200 毫秒宽限，再淡出。
3. 小图路径栏可返回祖先。“保留这一层”把当前层和真实进入路径加入正式图；普通右键菜单的“展开一层／收起这一层／清除手动展开”控制常驻分支，圆形菜单位于“局部分支”。
4. 默认隐藏 `source`、`source_archive` 的纯来源关系，以及 `exam_source`、`exam_paper` 来源页；正文也引用相同文件时保留知识关系。需要时点击“显示来源”，或使用节点菜单切换来源。
5. 小图每批最多显示 20 个邻居，可翻批；手动展开遵循当前节点上限，超限会提示并取消此次展开。
6. 按住 Ctrl（macOS 为 Command）悬浮节点，使用原有笔记预览。右键小图边、主图紫色边或临时节点，可查看这条真实关系的引用；面板内继续精确预览标题与块。
7. 点击预览节点在新标签页打开笔记；拖动、滚动、窗口失焦、切换中心或关闭开关会清理临时层。更换中心清理手动分支；手动分支不跨会话保存。

## 数据与接线

| 需求 | 实现及调用入口 | 验收 |
| --- | --- | --- |
| 一跳真实关联、方向、来源、分页 | `main → NeighborIndex → BranchExplorer`；首次查询构建索引，缓存解析后按源更新 | `branches-data.mjs` 验证双向引用、仅入链／出链、属性数组、来源页、正文混合引用、分页、编辑与删除 |
| 与正式图谱使用同一边级筛选 | `queryBranch → GraphFilter.filterData(预览模式)`；筛选后计算邻居及分页，预览模式不加外链或写状态栏 | 忽略正文链接和排除目标目录均先失败再通过；正式筛选的类型开关及源／目标禁用直接复用 |
| 手动展开、收起、共享所有权 | 普通与圆形菜单 → `BranchExplorer → BranchExpansions → dispatcher.updateData → GraphFilter` | 共享节点不被另一分支收起删除；保留深层真实路径；删除锚点不复活旧分支 |
| 双处临时预览 | 每个局部视图独立包装 `renderer.onNodeHover`；`BranchPreviewView` 同时驱动 SVG 和 Pixi 临时层 | `branches-ui.mjs` 验证同一开关、核心数据不变、主图命中与递归探索 |
| 稳定探索与淡入淡出 | `BranchExplorer` 维护悬浮区域、候选计时、路径和透明度；dispatcher 渲染回调推进动画 | 重绘不自动进入下一层、小图位置稳定、临时锚点不跳回原点、离开后清理 |
| 真实边的引用与原有预览 | 临时层命中 → `InputsManager.showRelations(target, source) → RelationsUI`；修饰键交给原悬浮回调 | 临时节点与边的实际端点、Ctrl 分流、原有心衰标题与块定位 |
| 中心与多视图 | `holdCenter` 共享引用计数；关闭、换中心和卸载释放包装及临时固定 | `center-pin.mjs`、视图隔离与关闭清理回归 |
| 真实样本 | 六篇 CMBK 笔记只读复制至独立库 | 心衰 → 利尿后口渴 → 尿生成调节；双处预览、递归、保留、实际边端点 |

临时层不会进入核心节点查找缓存。真实样本先复现了“保留后节点未被增强接管”；绘图重建期间的事件解绑也有独立失败测试，恢复后批量接管正式节点、边与文件夹，修复后通过。Hover Editor 源码与构建均未修改，未增加依赖或持久化配置。

## 验证及限制

Windows、Obsidian 1.15.0、默认深色主题；正式构建及心衰专项通过。常规回归共 27 项，其中 25 项通过；“初始化期间停用”和“停用插件恢复已打开图谱”两项历史失败按用户要求继续延期。

已检查正式包的双处预览、右侧工具栏开关，以及小图和引用面板并存时的避让和按钮换行。截图与结果仅保留在忽略目录 `.test-results`，不提交笔记和构建。

尚未覆盖移动端、最低宿主版本、第三方主题、全部插件组合、超大分支与长时间连续探索。主图临时节点使用独立放射布局，密集或靠边场景仍可重叠或超出视口，小图提供同一层的可见入口；不会为了避让而移动原图节点。
