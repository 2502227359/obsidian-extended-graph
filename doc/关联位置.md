# 局部图谱关联位置

## 范围与接口

- 入口：局部图谱文件节点菜单中的“查看与中心关联”。圆形菜单也提供同一入口；普通节点悬浮保持原行为。
- 查询接口：`readRelations(app, centerPath, neighborPath)`，只检查这两个文件的正向、反向引用，不建立全库索引。
- 显示：按引用方向、目标文件与位置分组，保留每次引用的来源小节、位置和原文。
- 预览：面板中的真实链接通过宿主悬浮预览通道交给现有 Hover Editor；点击在新标签页打开准确位置。
- 定位：支持标题、块、整篇引用；失效与歧义明确提示，不修改笔记或猜测替代位置。
- 组件：关联面板属于当前图谱，关闭或卸载时清理事件；异步读取不能覆盖更新后的文件对。
- 中心：面板打开时临时启用原生图谱固定，关闭后恢复原先未固定的状态；原先已固定的图谱保持固定。固定的预览浮窗交由用户管理。
- 切换：用户主动更换局部图谱中心时移除旧关系面板；鼠标移开只取消过期悬浮，不取消已经发出的点击打开请求。
- 本轮不修改 Hover Editor，不处理已延期的两项历史生命周期问题。

## 实现前约定的验收

1. 查询接口：重复引用合并、正反向区分、来源证据保留；无锚点、别名、重名文件及失效位置有明确结果。
2. 用户入口：节点菜单打开面板，来源取当前局部图谱；多面板和浮窗切换不串用活动文件。
3. 心衰样本：只读复制 CMBK 的《心力衰竭》和目标药理章到忽略的独立测试库，验证 21 个目标位置、34 处引用。
4. 宿主定位：真实 Hover Editor 预览至少两个不同标题与一个块；读取模式能正确滚动；点击打开和来源原文回跳准确。
5. 清理：关闭面板、关闭图谱和插件重载不残留本功能界面与监听；笔记变化后重新核对位置。
6. 交付：正式构建、针对性回归及界面验收通过后，部署三个正式插件文件到 CMBK；校验哈希并保留配置。

## 当前进度

已完成关联查询、普通及圆形节点菜单、图谱内关联面板与标准悬浮链接接线。

- 五项新增常规回归通过，覆盖重复与反向引用、编码和同名路径、属性与嵌入、读取竞态、菜单及面板、失效提示、关闭恢复固定状态及取消过期悬浮。
- 心衰专项在独立测试库中使用真实笔记副本与原有 Hover Editor 构建通过：21 个目标位置、34 处引用；两个不同标题进入阅读模式浮窗视口，一个真实块正确定位，预览及打开引用原文不会更换中心。
- 正式构建与原有图谱启停、图例、设置窗口界面验收通过。完整常规回归 18 项通过，2 项历史生命周期失败仍按用户要求延期。
- 操作：打开局部图谱并启用增强，在相邻文件节点的普通或圆形菜单中选择“查看与中心关联”；悬浮标题预览、点击打开新标签页，展开来源后可回到引用原文。
- 定位依赖宿主元数据缓存与预览行为；未覆盖最低宿主版本、第三方主题和移动端。遇到失效或同名标题会提示，原文不被自动修改。
