# 局部图谱关联位置

## 范围与接口

- 入口：局部图谱文件节点菜单中的“查看与中心关联”，圆形菜单提供同一入口；Alt＋左键直接打开位置列表并自动预览第一处。
- 查询接口：`readRelations(app, centerPath, neighborPath)`，只检查这两个文件的正向、反向引用，不建立全库索引。
- 显示：按引用方向、目标文件与位置分组，保留每次引用的来源小节、位置和原文。
- 预览：面板中的真实链接通过宿主悬浮预览通道交给现有 Hover Editor；菜单模式悬浮预览、点击打开标签页，Alt 直达模式点击切换浮窗、Ctrl／Command＋点击打开标签页。
- 定位：支持标题、块、整篇引用；失效与歧义明确提示，不修改笔记或猜测替代位置。
- 组件：关联面板属于当前图谱，关闭或卸载时清理事件；异步读取不能覆盖更新后的文件对。
- 中心：面板打开时临时启用原生图谱固定，关闭后恢复原先未固定的状态；原先已固定的图谱保持固定。固定的预览浮窗交由用户管理。
- 切换：用户主动更换局部图谱中心时移除旧关系面板；鼠标移开只取消过期悬浮，不取消已经发出的点击打开请求。
- 本轮不修改 Hover Editor，不处理已延期的两项历史生命周期问题。

## 实现前约定的验收

1. 查询接口：重复引用合并、正反向区分、来源证据保留；无锚点、别名、重名文件及失效位置有明确结果。
2. 用户入口：节点菜单打开面板，来源取当前局部图谱；多面板和浮窗切换不串用活动文件。
3. 心衰样本：只读复制 CMBK 的《心力衰竭》和目标药理章到忽略的独立测试库，验证 21 个目标位置、34 处引用。
4. 宿主定位：真实 Hover Editor 预览至少两个不同标题与一个块；读取模式能正确滚动；点击打开和来源原文回跳准确。
5. 清理：关闭面板、关闭图谱和插件重载不残留本功能界面与监听；笔记变化后重新核对位置。
6. 交付：正式构建、针对性回归及界面验收通过后，部署三个正式插件文件到 CMBK；校验哈希并保留配置。

## Alt＋左键直达浮窗

局部图谱启用增强后，按住 Alt 并左键单击文件节点，自动打开“关联位置”面板及第一处精确预览，不需要先开启“悬浮关联”。列表保留全部关联，当前预览条目以左侧色条标记；点击其他位置切换浮窗，展开“引用原文”后也可点击预览。Ctrl／Command＋点击仍在普通标签页打开。

目标有有效标题或块引用时定位目标段落；整篇链接、失效或同名标题改为预览第一处引用原文，不猜测目标段落。来源属性没有正文位置时只能显示来源笔记。没有直接引用时显示空列表，不自动打开普通笔记。

主图正式节点、主图临时节点和关系小图均支持这一手势。临时节点使用它当前真实连线的两个端点；正式节点使用局部根中心。拖动超过既有阈值不触发直达，其他组合键沿用原行为。自动预览复用现有 Hover Editor 延迟和显示设置；首次松开 Alt 不取消正在创建的浮窗，重复点击同一条目也可重新显示。点击外部或关闭面板清理未固定浮窗，用户固定的浮窗继续由用户管理。

实现由 `InputsManager.previewRelations → showRelations → RelationsUI` 接入；临时节点经 `BranchExplorer.open → BranchPreviewView.getRelationEdge` 取真实端点。直达模式单独取消过期点击读取，每次请求使用独立触发元素，避免 Hover Editor 对刚关闭目标的短暂屏蔽；不修改其源码或构建，不新增配置。

验收先复现缺失入口、取消预览和重复点击失败，再验证四项新增常规回归。心衰专项验证首个真实标题自动进入浮窗视口、21 个位置／34 处引用仍完整、点击切换及重复点击、真实块和第 471 行引用原文定位；开启自动聚焦时图谱根中心不变。
