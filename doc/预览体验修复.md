# 关联预览体验修复

本轮分两个独立提交，不推送。第一项修复长名称，第二项调整停靠与拖动；回退第二项仍保留第一项。两个提交分别升级补丁版本。

## 第一项：完整名称

- 当前笔记名称独立于探索路径，显示完整文件名（不含扩展名），保留编号，不使用图中节点的短名称。
- 默认最多三行，超出时提供展开／收起全文；宽窄布局均不产生横向溢出。标题提示完整路径。
- 祖先路径单独显示，仍可返回；图中节点继续保持紧凑名称和完整路径提示。
- 验证长中文标题、展开／收起、祖先返回、同名路径、已有主题、布局和递归探索。

已完成，版本 2.7.9。两项新增回归先复现标题不存在，再验证完整名称、三行展开／收起及祖先返回；与递归探索、面板避让、键盘和主题共六项相关回归通过，正式构建通过。探索路径行保留固定高度，避免进入下一层时因多出路径行而挤动窗口；名称展开后仅在确实越界时向上钳制位置。

## 第二项：预览布局

- 宽窗开启悬浮关联期间，为右侧预览区预留空间，主图使用剩余实际画布；悬浮只换内容，不反复改变画布大小。
- 窄窗保留靠边浮窗，允许拖动，记住当前视图位置；更换预览节点不跳回原位。
- 关闭悬浮、关闭视图或卸载时恢复画布；保留拖动、Alt 定位、引用面板避让及减少动态效果。

已完成，版本 2.7.10。图谱区域宽度达到 880 像素时，开启悬浮关联会预留 344 像素轨道，预览卡宽 320 像素；暂时离开只隐藏内容，不反复改变画布大小。关闭开关恢复完整画布。窄窗使用靠边浮窗，拖动标题栏可移动，当前位置仅在当前视图内保留；已有引用面板仍参与避让。

### 接线与验证

- `BranchExplorer.toggle → BranchPreviewView.setEnabled → PreviewLayout` 管理停靠生命周期；`ResizeObserver` 处理宽窄及同模式尺寸变化，关闭后交还宿主缩放。
- 同级真实 viewport 提供主图剩余区域尺寸，canvas／iframe 留在原位，通过局部样式同步实际宽度。仅在停靠期间调整 `renderer.containerEl`，调用宿主 `onResize()` 同步 Pixi、交互画布和居中；不调用 `setData()`，不移动 iframe、不重建节点。
- `BranchPreviewView.positionDocked` 在轨道中摆放预览及引用面板；返回浮动模式清除停靠位置缓存。拖动由 `PreviewLayout` 接收标题栏按下和窗口移动／松开／取消事件，并限制在当前视图内、避开引用面板。
- 三项新增布局回归通过，复用正式节点和临时节点的宿主命中、拖动、右键及 Alt 定位验收；覆盖同模式缩放、宽窄往返、iframe 文档不变、暂离尺寸稳定、关闭和停用还原。两项尺寸边界均先观察失败再修复。
- 全量 54 项通过 52 项，仅剩两项已延期生命周期失败；正式构建通过。旧测试会话曾额外出现保存期间重新启用超时，完整重载测试库后，当前版本的单项及完整回归均通过，未修改该生命周期逻辑。
- 已检查真实宿主浅色截图：宽窗主图与轨道不重叠，完整标题换行；620 像素窄窗恢复浮动。截图、测试结果及两个版本的正式包保留在忽略目录。
- 心衰逐层探索、Alt 真实段落定位两项专项以及正式包启停／图例／设置验收通过。截图恢复窗口后曾因后台状态导致专项失败，恢复可见后通过，未放宽断言。
- CMBK 已加载 2.7.10，保留原图谱启用与悬浮开关状态；三个正式文件与源一致，12 项保护文件重载后哈希一致，未新增错误。重载产生的内部折叠状态备份已核对并恢复，同步内存后恢复配置原始字节。
- CMBK 当前图谱区域宽 832 像素，运行窄窗浮动模式；加宽到 880 像素以上可试用右侧停靠。没有替用户调整侧栏或窗口大小。
