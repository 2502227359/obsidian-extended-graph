# 局部图谱层数切换

## 验收约定

- 只在已启用增强的局部图谱显示右上角 `1层 / 2层 / 3层`，单击直接切换；原生设置折叠后仍可用，当前层数有明确选中状态。
- 层数表示从中心开始的最短链接距离。复用核心图谱深度、方向与搜索筛选，不遍历整库后另造节点集合，不增加依赖或持久化配置。
- 原生深度滑块、插件状态切换与新控件双向同步；原生选择其他深度时不能误标为 1、2、3 层。
- 每个局部视图独立。切换清理临时悬浮，但保留悬浮开关和用户主动保留的分支；层数控制基础图，手动分支仍可超出基础层数。
- 真实宿主中验证四层链逐级出现和收回、原生同步、两个局部视图互不干扰、键盘操作、窄窗和设置展开/折叠、卸载清理。
- 版本同步升为 2.7.8。通过相关回归和正式构建后部署 CMBK 的三个正式文件，不修改 Hover Editor、笔记和用户快捷键。

## 实现与接线

- `GraphEventsDispatcher.initializeUI → BranchExplorer / LocalDepthControl` 创建局部工具栏，悬浮图标和三个层数按钮并列；原生设置展开后向下避让。
- `LocalDepthControl.select → engine.setOptions({ localJumps }) → renderer.setData → GraphEventsDispatcher.updateData` 复用核心节点构建、过滤和上限检查。按钮自身不查询全库、不直接注入节点。
- `updateData → LocalDepthControl.sync / BranchExplorer.beforeGraphicsReset` 同步实际层数、清除旧临时预览；手动分支继续参与 `mergeData`。原生滑块和插件状态应用进入相同路径。
- 图谱帧只比较层数与状态是否就绪，未变化时不改 DOM。初始化／状态应用期间按钮暂不可用，完成后恢复，防止在撤销记录未就绪时误触。
- 方向键、Home／End 切换并移动焦点，Enter／Space 使用原生按钮行为；保留明确焦点轮廓和减少动态效果支持。原生深度 4／5 时三个快捷按钮均不选中。
- 启用既有“超限撤销”时，深度回退直接恢复上一个 `localJumps`，同步原生滑块与快捷按钮；不再向无关复选框派发点击。关闭该设置时沿用已有超限处理策略。
