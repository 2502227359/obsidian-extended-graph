# 插件维护与测试

## 独立测试库

测试库位于项目根目录的 `.test-vault`，只含自动生成的笔记和测试插件，不连接个人笔记库，也不初始化 Git。测试库、构建产物、截图和运行结果均不提交。

已验证环境：Windows、Node.js 24.22.0、Obsidian 1.14.4，依赖使用现有锁文件，未升级版本。

首次准备：

```powershell
npm ci --ignore-scripts --no-audit --no-fund
npm run test:setup
```

在 Obsidian 的管理库界面选择“打开文件夹作为库”，打开本项目的 `.test-vault`。只在这个库中允许第三方插件，并开启 Extended Graph。Obsidian 的命令行接口需要提前启用，具体设置见 [官方 CLI 文档](https://help.obsidian.md/cli)。

测试脚本始终传入 `vault=.test-vault`，并核对该库的绝对路径。不能把脚本改成自动选取当前活动库。

## 回归与界面验收

```powershell
# 在真实 Obsidian 中运行全部回归，部署带测试入口的独立构建
npm test

# 只运行指定用例
npm test -- 旧配置升级保留用户设置

# 构建并部署正式插件，检查图谱启停、可见图例和设置窗口
npm run test:smoke
```

可通过 `OBSIDIAN_CLI` 环境变量指定命令行程序路径。Obsidian 必须正在运行且测试库已打开。测试插件由 `tests/plugin-entry.mjs` 单独打包；正式构建仍从 `src/main.ts` 开始，不含测试入口。

`test:setup` 不覆盖已存在的测试笔记，会更新测试库中的插件构建。回归会打开、关闭图谱，临时改写测试笔记和配置，并在结束时恢复相关内容。界面验收会把标签图例、状态面板设为展开，最后保留正式插件和一个可手动操作的图谱。

结果位于 `.test-results/regressions.json`；界面截图为 `.test-results/graph.png` 和 `.test-results/settings.png`。Obsidian 1.14.4 的设置使用独立窗口，设置截图从该窗口捕获。

运行日志：

```powershell
obsidian vault=.test-vault dev:debug on
obsidian vault=.test-vault dev:errors
obsidian vault=.test-vault dev:console level=error
```

## 本轮需求、实现和验收对应

| 问题 | 实现与调用入口 | 验收证据 |
| --- | --- | --- |
| 标准构建失败 | `InputsManager` 将原生事件传给 Obsidian 的修饰键 API | `npm run build`；真实指针事件开始、结束框选 |
| 停用后图谱代理与控件残留 | `GraphsManager.onunload` 清理视图组件；图谱 UI 随管理器卸载；关闭视图移除 dispatcher | 停用后核心方法恢复、控件和状态栏清空，重启后仅一组控件 |
| 初始化期间停用 | `Graph`、dispatcher、状态切换检查组件存活；生命周期管理器按请求取消延迟启用 | 初始化中停用、同步保存时停用均不复活；保存时关闭图谱后同一标签页可再次启用 |
| 旧字段提前删除 | `loadSettings → migrateSettings` 在转换旧字段后清理未知字段 | 图片、图标、尺寸属性、名称属性和统计方向保留；旧键被删除 |
| 旧配置缺少默认状态 | `migrateSettings` 补入独立的默认状态 | `states: []` 可以加载，默认状态存在 |
| 状态配置先读后写 | `saveConfigForState → exportSettings → mkdir/write → loadConfigFile` 依次等待 | 文件写入延迟时，首次保存与覆盖均读到最新配置 |
| 多图元数据更新中断 | `metadataCache.changed → GraphsManager.onMetadataCacheChange` 跳过缺少节点的图 | 第一个图谱排除笔记时，后面的图谱仍更新标签 |
| 前后向链接统计反转 | `NodeStatCalculatorFactory` 按方向选择入边、出边计算器 | 正常、反向以及唯一计数、重复计数四组组合 |
| 共引计算提前返回 | `LinkStatCalculator → CoCitationsCalculator` 依次等待引用笔记读取 | 真实笔记同句共引分数为 1，不再得到 undefined |
| 动态统计缓存过期 | `LinkStatCalculator.getStats` 在每次计算开始清空共享缓存 | 同一计算器更新图后，Jaccard 从 0 变为 1/3，新目标也有有效值 |
| 文件夹查询匹配完整路径 | `RuleQuery.doesMatch` 使用父文件夹路径 | 父文件夹匹配，完整文件路径不匹配 |
| SVG 裁掉零坐标区域 | 实际 SVG 组装流程区分零值与未初始化值 | 浏览器实际测量后 viewBox 为 `0 0 110 110` |

全部用例通过公共调用入口验证可观察结果。文件写入延迟只施加在 Obsidian 文件适配器边界，内部计算器、配置迁移、查询与图谱组件均使用正式源码。每项修复先运行对应失败用例，再修改实现。

## 未覆盖范围

- 未验证最低声明版本 Obsidian 1.7.0，也未覆盖移动端、大型笔记库、第三方插件共存和长时间运行。
- 统计监听器仍采用原有异步通知机制；`computeStats()` 不保证等待所有后续图重建任务，异步异常传播和重复监听注册需要单独治理。本轮共引测试验证最终结果，不把轮询完成等同于 Promise 完成契约。
- 图片、视频、全部统计公式和各类导出选项未做穷举验收。测试通过不能据此推断插件已无其他历史缺陷。
